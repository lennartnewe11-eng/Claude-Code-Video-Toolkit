# See — Video-Beschreibung

**Kurz:**
Wie entsteht eigentlich ein See? 🌊 Vom schmelzenden Toteisblock über abgeschnürte
Flussschlingen bis zum gefluteten Braunkohletagebau: So unterschiedlich Seen entstehen —
am Ende zählt immer dieselbe Bedingung: ein Becken, das Wasser hält, und genug Wasser,
das hineinläuft. Doch kein See bleibt für immer. Aus dem See wird ein Sumpf, aus dem
Sumpf eine Wiese — ein kurzer, nasser Moment in der Geschichte einer Landschaft.

**Ein-Zeiler:**
Wie entsteht ein See – und warum bleibt keiner für immer? 🌊

**Noch kürzer (Social):**
Ein Becken + genug Wasser = ein See. Doch keiner bleibt für immer. 🌊
