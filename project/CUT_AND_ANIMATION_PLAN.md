## Technischer Workflow (nächste Session)

```bash
# 1. Tools (Hook installiert sie automatisch; sonst:)
bash project/tools/setup.sh

# 2. Footage laden (Beispiel, sobald Netzwerk-Policy es erlaubt)
#    Lizenzfrei bevorzugen!
yt-dlp -f "bestvideo[height<=1080]" -o "project/footage/%(title)s.%(ext)s" "<URL>"

# 3. Clip frame-genau auf ein Segment schneiden (Bsp. Shinkansen 1.4–5.0s der Tonspur)
project/tools/ffmpeg -ss 0 -i project/footage/shinkansen.mp4 -t 3.6 \
  -vf "scale=3840:2160:force_original_aspect_ratio=increase,crop=3840:2160" \
  -an project/renders/clip_hook_01.mp4

# 4. Audio aus Original-.mov behalten, neues Bild drüberlegen → finaler Schnitt
#    (Remotion-Timeline ODER ffmpeg-concat + -map audio aus 0615_2.mov)
```

**Empfehlung:** Gerüst (Karten, Charts, Typo, Titel) in **Remotion** bauen → exakt auf die SRT-Timecodes setzen. Echtes Footage als `<OffthreadVideo>` einbetten. Original-Audio aus `0615_2.mov` als durchgehende Tonspur.
